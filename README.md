# RED FOX — Galaxy Invaders

Встраиваемая версия оригинальной игры из [patnaikshekhar/GalaxyInvaders](https://github.com/patnaikshekhar/GalaxyInvaders). Используются исходный JavaScript-движок, сцены, спрайт-лист и звуковые файлы. Источник зафиксирован на ревизии `9d82210b4ca1679f492c9153657f9055ba3467fd`.

## Встраивание на страницу задания RED FOX

В блоке задания оставьте контейнер `.oPos.nobr` и добавьте загрузчик:

```html
<div class="oPos nobr">&nbsp;</div>
<script src="https://cdn.jsdelivr.net/gh/RedLine142/redfox-galaxian@9674c000f1dff3a43d1a770a4d2e7830f18dc900/redfox-galaxian-embed.js"></script>
```

## Управление

- Стрелки влево / вправо — перемещение корабля.
- Пробел — начать игру, стрелять и перезапустить после Game Over.
- На телефонах доступны экранные кнопки «Влево», «Старт / огонь», «Вправо»; удержание кнопок повторяет действие.
- Корабль ограничен шириной игрового поля и не уходит за его края.
- Частота выстрелов противников снижена примерно втрое.

Игровое поле 640 × 480, встраивается в адаптивное окно с пропорциями 4:3.

## Тестирование

Браузерная проверка сборки подтвердила появление canvas, русских подсказок, отсутствие ошибок загрузки и переход из меню в игровой режим по пробелу. После этого добавлена защита от повторной обработки столкновений; финальные HTML и JS-модули доступны по HTTP 200. Полный повторный браузерный прогон после последней правки столкновений не завершился из-за тайм-аута тестового браузера, поэтому эту последнюю правку дополнительно проверил по коду, но не отмечаю её как полностью проверенную в игре.
