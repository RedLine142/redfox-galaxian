# RED FOX — Galaxy Invaders

Встраиваемая версия игры на основе оригинального проекта [patnaikshekhar/GalaxyInvaders](https://github.com/patnaikshekhar/GalaxyInvaders). Используются исходный движок, сцены, спрайты и звуковые файлы.

## Встраивание на страницу RED FOX

Оставьте существующий контейнер .oPos.nobr и подключите загрузчик. Если контейнер уже есть, не добавляйте его второй раз.

```html
<div class="oPos nobr">&nbsp;</div>
<script src="https://cdn.jsdelivr.net/gh/RedLine142/redfox-galaxian@f42446a69de0eb4cc719ee4039eb89e46e33824e/redfox-galaxian-embed.js"></script>
```

## Управление

- Удерживайте стрелку ← или → — корабль движется непрерывно, пока клавиша нажата.
- Перемещайте мышь по игровому полю — корабль следует за курсором.
- Пробел — начать игру и стрелять; на экране завершения — начать заново.
- На сенсорных устройствах доступны экранные кнопки влево, старт/огонь и вправо.

## Игровая кампания

- Ровно 3 уровня, по одной волне противников на каждом.
- В начале игры 2 жизни: основная и одна дополнительная. После потери первой жизни корабль возрождается.
- Очки полностью убраны. В игровом HUD показываются только номер уровня и оставшиеся жизни.
- После первого уровня появляется надпись «м», после второго — «над», после третьего — «небо».
- После «небо» остаётся только возможность начать игру сначала клавишей Пробел.
- Скорость движения противников постепенно увеличивается от уровня к уровню.

## Проверки

- Проверен синтаксис всех изменённых JavaScript-файлов и встроенных скриптов HTML.
- Проверены по отдельности непрерывное движение при удержании стрелки и ограничение корабля границами поля.
- Проверена логика трёх уровней, последовательность слов, две жизни, возрождение и экран перезапуска с помощью изолированных тестов игровой сцены.
- Финальные закреплённые игровые модули и загрузчик доступны по HTTP 200.
- Полный визуальный прогон в браузере с управлением мышью и фактическим прохождением всех волн не удалось завершить из-за тайм-аутов браузерной проверки; это не отмечается как подтверждённый end-to-end тест.
